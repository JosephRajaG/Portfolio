# Joseph Raja G — Developer Portfolio

A modern, high-performance, one-page personal developer portfolio built with React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide React.

![Portfolio Preview]

## 🚀 Features

- **Linear / Vercel Dark Theme**: Sleek obsidian background (`#030712`) with electric cyan and purple gradient accents.
- **Glassmorphism UI**: Translucent layered cards, dynamic glowing borders, and backdrop blurs.
- **Dynamic Typing Roles**: Animated typewriter cycling through engineering roles.
- **One-Page Navigation**: Smooth scrolling with real-time active section indicator and top scroll progress bar.
- **10 Core Sections**:
  1. **Hero**: Headline, bio, typing roles, social links, resume download, and profile card.
  2. **About Me**: Academic standing at KIT Coimbatore (CGPA 7.9/10), CS coursework, and engineering pillars.
  3. **Technical Skills**: Categorized skills across Languages, Frontend, Backend, Databases, AI/ML, Tools, and Core CS Fundamentals.
  4. **Featured Projects**: Deep-dive cards and architecture modals for:
     - *AI Tutor – Emotion Adaptive Learning Platform*
     - *AI Powered Travel Planner*
     - *AI Data Quality Copilot for B2B Datasets*
  5. **Experience**: Offline Full Stack Development Internship at LearnLogicify Technologies.
  6. **Competitive Programming**: Statistics cards for LeetCode (1690 Max, 300+ Solved, Top 3.4%), CodeChef (1544, 2-Star), Codeforces, and AtCoder.
  7. **Achievements**: Honors at IIT Madras Shaastra 2026 NeuroHACK (Offline Finalist) & KIT 24h Hackathon (Top 25).
  8. **Certifications**: Verified credentials from Cisco, Infosys Springboard, LearnLogicify, and Coursera.
  9. **Contact**: Direct email/phone copy with feedback tooltips, contact form, and celebratory confetti burst with `mailto:` fallback.
  10. **Footer**: Social profile links, back-to-top button, and copyright.

## 📦 Getting Started

### Prerequisites

- Node.js (v18+ or v20+)
- npm / pnpm / yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/JosephRajaG/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```
